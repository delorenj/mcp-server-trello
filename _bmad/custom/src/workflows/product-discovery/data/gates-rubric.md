# Gates Rubric — Scoring Worksheet

Used by step-04-idea-select. This is the worksheet; the **authoritative gate text is the product doctrine skill** (`mcp-server-trello-product-doctrine`). When this sheet and the doctrine disagree, the doctrine wins — update this sheet.

---

## Epistemic Markers (score nothing without them)

- **VERIFIED** — command run this session, output citable
- **BELIEVED** — plausible, load-bearing, unchecked. **Cannot kill an idea.**
- **FALSIFIED** — checked and false; recorded so nobody relitigates

> If a claim is doing real work in a decision, it gets verified BEFORE the decision lands.

## Gate Order (kill-shot order — stop at first kill)

| # | Gate | Question | Kills when |
|---|------|----------|-----------|
| 0 | Prior kill | Was this killed before? | Kill reason still stands and isn't addressed |
| 1 | Convention | Does the data exist on a live board, written by nobody, unprompted? | Data is convened and no writer tool ships first |
| 2 | Loop | If it reads, who writes? If it writes, who reads? | Half a loop, and the missing half isn't the writer |
| 3 | Frequency × judgment | Honest invocation frequency? | Quarterly frequency, even with brilliant judgment |
| 4 | Slot ledger | What does it retire? Classification? | Addition-only with no retirement argument |
| 5 | Find-and-replace | Ships unchanged on Linear/Jira? | Generic AND claims Trello judgment (compression exempt) |
| — | North Star | Could an LLM do it in 3 existing calls, no real loss? | Yes, and the reason isn't capability / compression-before-payment / determinism |

## Standing Tests (survivors only)

- **Silent-wrong** — false assumption → null + named reason, never a plausible value
- **Division of labor** — tool does determinism + refusal; LLM does semantics
- **Board shape** — works on a real, messy board (emoji lanes, missing prefixes, one member)
- **Mutation trust** — a fix applied to a card that didn't need it is a no-op
- **Demand** — behavioral evidence only; never fabricated
- **Surfaced, not queried** — prefer ride-along fields over tools nobody remembers to call

## Verdict Format

Per idea: `SURVIVED` (with gate record + standing-test concerns) or `KILLED at Gate N` (reason + claim status + relitigation note). The winner needs one paragraph of frequency × judgment × slot math against the other survivors.
